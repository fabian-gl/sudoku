# 🧩 Sudoku Solver & Game

A classic **Sudoku game** built with a smart twist — it features an automatic **backtracking algorithm** that can solve puzzles of any difficulty.

---

## 🚀 About the Project

This project combines the fun of Sudoku with the beauty of algorithmic problem-solving. It includes both a playable grid and a built-in solver powered by **recursive backtracking** — a popular technique in constraint satisfaction problems.

Whether you're just playing or diving into code, this project is perfect for:
- 🧠 Understanding backtracking algorithms
- 🎮 Playing Sudoku
- 💻 Practicing coding logic

---

## 🧠 How It Works

Sudoku is solved using a **backtracking algorithm**:
1. Finds empty cells
2. Tries valid numbers (1–9)
3. Recursively explores each possibility
4. Backtracks when it hits a dead end

This process continues until a valid solution is found — or all possibilities are exhausted.
